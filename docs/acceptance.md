# 桌面验收

<!-- 2026-11-19：新增第四轮数据迁移、故障诊断及 Windows 安装验收。 -->
<!-- 2026-11-21：写作目录绑定需要 SQLite 结构版本 6。 -->
用户已通过第一轮的依赖安装和桌面启动，并确认已验收第二轮。第三轮题源与第四轮数据、安装程序分别按下文验收。运行当前版本时，设置页的 SQLite 结构版本应为 6。

<!-- 2026-11-21：同步当前构建的数据库版本。 -->
1. 按 [README](../README.md) 启动桌面应用。检查窗口标题为 IETLS4PASS，开发端口为 1422。进入设置打开数据检查，确认数据库为 `ietls4pass.db`，SQLite 检查返回 `ok`。第二轮历史构建的版本为 2，当前构建的版本为 6。使用已有第一轮数据库时，核对先前成绩和草稿仍可读取。
2. 打开阅读题库，核对总数为 239 篇。P1、P2、P3 应分别显示 74、78、87 篇。搜索 `p1-high-01` 可打开对应阅读。
3. 用 `p1-high-01` 分别通过键盘选择和拖放完成匹配。用 `p1-high-118` 检查共用多选题组，用 `p2-high-134` 查看题图。对每个代表题在原版与桌面输入相同答案，检查各题得分和总分。检查 `p3-low-240` 的缺失解析状态。
4. 开始答题后暂停、切换到其他应用再切回。前台有效用时应在暂停及失焦期间保持不变。离开阅读页、重启并恢复草稿，核对作答和值。
5. 提交一份练习，在历史详情查看作答、标准答案和每题得分。退出并重启桌面应用，检查历史保留，已提交草稿已清理。同一提交 ID 应只创建一条历史。
<!-- 2026-11-20：验收单篇阅读与新版导航。 -->
6. 在阅读练习中打开一篇文章，作答后点击「返回阅读练习」，再从列表打开同一篇，核对已填写的答案。
7. 提交两次同一篇阅读，核对列表的最近得分和提交历史。作答后返回列表时，确认未提交的草稿不计入总览提交次数。
8. 在设置下载备份，再导入同一文件。检查重复成绩的新增数为 0。导入一个上游 v1 或 v2 成绩文件，核对原题、原分数、原用时、答案和重复导入结果。
9. 在设置中绑定含 10 题 Section 和同名音频的听力目录，返回听力首页按场景选题。作答若干题后保存并返回，检查列表显示「继续做题」。续做时核对答案及用时，完成提交后检查列表的 `x/10` 和历史记录类型。打开「静听练习」，验证播放、调速和循环。
10. 在词汇页完成一次复习并重启应用，检查对应单词的下一次到期时间影响待复习列表。切换浅色和深色后重启，确认设置已保存。

## 第二轮专项

1. 打开阅读后先停留在原文，再点导航题号或按 Tab 进入答题控件。确认出现对应归属。选中同一共享题组内的两个题号，提交后确认记录详情里只出现一次题组时长。单击原文或使用“设为未分配”后，之后的有效间隔应进未分配。
2. 作答后暂停，等待后离开并重新打开。确认草稿暂停状态、已保存的答案和计时保留。继续时归属回到未分配。切到其他应用后再切回，检查关联时长排除失焦段。旧记录查看计时应提示缺少可靠数据。
3. 在阅读原文选中一段文字并高亮，标记一道题，写一条笔记。离开并恢复草稿后核对三项内容。提交后在记录页打开“回放本次作答”，修改并保存批注。回到记录检查得分和计时仍是提交值。
4. 用一篇新题提交非满分成绩，在题库检查回放及复习日期。通过回放选择一次反馈，检查计划日期更新，历史成绩数保持一致。另用一篇从未练习的文章提交满分，确认首个满分成绩未生成计划。准备两个窗口时，可对同一回放反馈，检查第二个旧版本收到冲突提示。
<!-- 2026-11-20：验收单篇阅读与新版导航。 -->
5. 从阅读题库打开一篇未完成的练习，核对恢复的答案、计时和暂停状态。
<!-- 2026-11-20：验收单篇阅读与新版导航。 -->
6. 恢复单篇阅读草稿并提交，在练习记录打开本次回放，核对分数、答案和批注。
7. 仅在愿意验证短期存储失败时，打开两个桌面窗口并进入同一篇草稿。在第二个窗口恢复后，第一窗口继续输入，应收到写入权变更提示。重新打开草稿时应以最近成功保存的版本为准。

## 第四轮专项

<!-- 2026-11-21：同步当前构建的 SQLite 版本。 -->
1. 在项目根目录运行 `pnpm tauri dev`。在「设置 → 数据检查」核对 SQLite 结果 `ok`，旧成绩、词汇和草稿仍可读取。第四轮历史构建的版本为 4，当前构建的版本为 6。
2. 下载桌面备份后选择同一文件，确认预览列出重复数量。合并完成时新增数应为 0。编辑一处备份内容后再选，确认校验失败。另选早期无校验的桌面备份，确认可按结构预览。
3. 下载起始备份，添加一条可区分的新练习，再选择起始备份并覆盖。检查新增记录从当前工作区移除，自动回退点可在预览后恢复新增记录。重新预览前若从另一窗口修改设置，先提交的恢复应提示工作区已变化。换机恢复时，为已恢复的目录题库重新选择对应路径，核对历史题库 ID、题图和 PDF。
4. 在原版导出真实 v2 备份，用桌面设置页预览合并。抽查一份单篇阅读成绩及其作答和笔记、一条文章复习计划、一条词汇到期进度，以及一份单篇阅读草稿。若有包含套题和普通记录的旧备份，合并后核对普通记录可以打开。重复合并时同标识状态应保持本机版本。用原版 v1 成绩文件对照一次历史分数和时间。
5. 在设置开启 15 分钟详细记录，执行一次正常数据检查及一次无效备份导入。导出报告，核对操作、结果、时间和版本，检查报告只有结构化诊断字段。结束详细记录，清除并停用诊断后，再触发失败并刷新，事件应保持清空。SQLite 启动失败的场景在独立测试配置中验证，设置页应可以打开并导出内存诊断。

## Windows 安装程序

在项目根目录运行下列命令。

```powershell
pnpm tauri build
node scripts/verify-release.mjs
```

在标准 Windows 用户或测试环境中安装 `src-tauri/target/release/bundle/nsis/` 下的 `*-setup.exe`。核对中文／英文选择、开始菜单启动、设置中的 SQLite 检查、内置阅读题库、媒体及备份往返。电脑缺少 WebView2 时，安装程序通过下载引导程序安装运行时。再从系统设置卸载，核对快捷方式与安装目录清理，并用下载的备份验证重装恢复。
