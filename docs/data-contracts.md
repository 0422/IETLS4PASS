# 数据契约

## 阅读题库

<!-- 2026-11-21：记录迁移后的阅读数据入口。 -->
默认题库的索引为 `data/reading/index.json`，架构标识为 `IETLS4PASSBankV1`。该索引目录下的 `reading/<examId>.json` 包含 `exam` 和可空的 `explanation`。题目源 ID 和退役 ID 映射随索引保留。原始题型、题组、题目编号、答案、文章富文本和解析保存在对应文件中。

2026-11-23 起，通过「设置 → 系统 → 资源目录」指定阅读目录时，使用和默认题库相同的 `index.json` 与单篇文件结构。旧备份中的单文件阅读题库沿用下表结构。

| 字段 | 意义 |
|---|---|
| `format` | 固定为 `ietls4pass-reading-bank-v1` |
| `title` | 题库显示名称 |
| `assets` | 由 `{ "exam": ..., "explanation": ... }` 组成的数组，结构可参考默认题库的转换输出 |

每篇 `exam.examId` 在同题库中唯一，分类为 `P1`、`P2` 或 `P3`。`exam.passage.blocks` 存放文章片段，`questionGroups` 存放题组 HTML 和题目 ID，`questionOrder` 列出顺序，`answerKey` 以题目 ID 查询答案。使用目录题库时，图片应保留题目引用的相对路径。

## 自备听力

<!-- 2026-11-19：听力题库按场景和 Section 展示，独立保存并评分。 -->
<!-- 2026-11-20：同步听力目录示例和分类清除操作。 -->
听力题库以 Section 为单位，默认从 `data/listening/` 读取。可以在「设置 → 系统 → 资源目录」更换目录。按场景整理时可采用 `data/listening/住宿/剑雅16 Test 4-Section 1.json`，同目录的同名 `.mp3` 会与题目关联。旧目录名「租房」「改造建设」「医疗」分别对应「住宿」「建筑环境」「健康医疗」。

<!-- 2026-11-20：明确目录条目与本地题源的匹配方式，提供可验证的单节模板。 -->
<!-- 2026-11-20：补齐 16 个场景后同步分册目录和缺资料状态的说明。 -->
按场景和按顺序的目录条目通过书号、Test 和 Section 与本地题源匹配。文件名里的 `Section 2` 和 `Part 2` 均表示第二节。自备 JSON 的 `part` 要与文件名一致。音频、题图和关联资料可放在同一目录，保留文件名或 JSON 里的相对路径。

| 字段 | 填写方式 |
|---|---|
| `format` | 固定为 `ietls4pass-listening-v1` |
| `parts` | 每个本地文件写一节，数组里放一个对象 |
| `parts[0].part` | 分节编号，整数 `1` 至 `4` |
| `parts[0].questions` | 按原题顺序填写 10 题，题号按 Part 自动生成 |
| `prompt` | 题干文字，填空位置可用 `____` 标出 |
| `answer` | 正确答案用字符串填写，也可用字符串数组列出多个可接受的写法 |
| `options` | 单选题填写选项字符串数组，正确答案填写对应的完整选项文字。省略时显示文本输入框 |
| `explanation` | 可选的逐题解析文字，在「详解」中显示 |

<!-- 2026-11-20：说明列表操作和 JSON 逐题解析字段。 -->
点击「答题」时，做题页读取该文件的 `questions`，按顺序呈现题干和输入框或下拉选项。输入框显示在题干旁边。Part 1 至 Part 4 的起始题号分别是 1、11、21、31。JSON 可省略 `title`，解析时会用文件名补上。

「详解」直接显示标准答案，并展示题目中填写的 `explanation`，例如 `"explanation": "录音最后确认了面试时间为九点半。"`。「精听」用于播放音频和调速、循环。缺少题目或音频时，对应操作会置灰并提示需要什么资料。旧版已导入的短资料仍可在列表查看已有答案和手动选择精听音频。

以下是 `剑雅21 Test 1-Section 2.json` 的完整格式示例，示例中的题目和答案为虚构内容。

```json
{
  "format": "ietls4pass-listening-v1",
  "parts": [
    {
      "part": 2,
      "questions": [
        { "prompt": "The interview starts at ____.", "answer": ["9:30", "9.30"] },
        { "prompt": "Bring a ____ to the interview.", "answer": "passport" },
        { "prompt": "Which day is the training?", "options": ["A. Monday", "B. Tuesday", "C. Friday"], "answer": "B. Tuesday" },
        { "prompt": "The training lasts ____ hours.", "answer": "3" },
        { "prompt": "Ask for ____ at reception.", "answer": "Jordan" },
        { "prompt": "The entrance is beside the ____.", "answer": "library" },
        { "prompt": "Staff need to wear ____ shoes.", "answer": "black" },
        { "prompt": "Applications close in ____.", "answer": "May" },
        { "prompt": "The nearest bus stop is on ____ Street.", "answer": "King" },
        { "prompt": "Which team has vacancies?", "options": ["A. Sales", "B. Finance", "C. Support"], "answer": "C. Support" }
      ]
    }
  ]
}
```

<!-- 2026-11-21：听力做题页停用手选 PDF，参考资料随本节目录关联。 -->
每节满分 10，列表的「我的结果」显示最新一次提交的正确题数和满分。续做保存答题、已计时长和播放位置。重新做题可替换同节未提交草稿，已提交的成绩仍可在练习记录查看。静听可调速和循环播放。目录题源可直接关联本地媒体，缺少已关联录音时可以手动选择音频。

「按顺序」视图按剑雅20至剑雅5展示，每册四个 Test，每个 Test 有 Section 1–4。剑雅12按资料里的 Test 5–8 展示。听力目录下可直接放 `剑雅听力导出/剑雅20/Test 1/Test 1_Section 1.json` 及同目录录音。软件从 `meta.subTitle` 读取副标题，识别 `listening.audioFile` 或同名 MP3，并按 `listening.sentences` 中每句的 `start` 和 `end`（秒）高亮 `en`。在精听页点击带时间的句子可跳转到该句起点。

<!-- 2026-11-20：记录导出成功后的题组、评分和本地图片关联。 -->

导出中的 `questions.ok: false` 对应精听资料。对已导出题面，软件用 `questions.raw.data.navList` 和 `contentList` 关联题号和答题控件，按 `questions.images` 查找同一 Test 目录下的相对图片路径。评分优先使用 `answers[].accepted`，缺失时回退至 `rightAnswer` 或旧版答案字段。详解和交卷结果读取 `analysis[].text`。未识别题型可以通过 `questions.questionText` 预览，也可沿用 `ietls4pass-listening-v1` 或 `questions.items` 的结构化题源。

## 口语题库

<!-- 2026-11-19：记录 Artifex 题源的落盘位置和增量更新方式。 -->
<!-- 2026-11-21：自动绑定现有 Writing 子目录，兼容设置中的独立目录选择。 -->
默认从 `data/speaking/` 下扫描 UTF-8 JSON。可用 `Part 1/`、`Part 2/` 和 `Part 3/` 子目录整理资料，每份文件填写对应 Part。新增话题时可添加同格式文件。迁移已有题库时，复制这些资料文件。

```json
{
  "format": "ietls4pass-speaking-v1",
  "part": 1,
  "topics": [
    {
      "id": "my-weekend-001",
      "category": "休闲活动类",
      "title": "Weekends",
      "questions": ["What do you usually do at weekends?"]
    }
  ]
}
```

每个话题填写 `id`、`category`、`title` 和至少一种题目内容。`questions` 为按顺序排列的问题，`cueCard` 可填写 Part 2 题卡原文。`book` 和 `difficulty` 可选。`part` 与 `id` 共同标识话题，同一 Part 新增话题时使用新 ID。已损坏的文件会在口语页提示，其他可读取文件仍会展示。

## 写作题库

将题目 JSON 放入 `data/writing/Task 1/` 或 `data/writing/Task 2/` 的分类目录。`meta.task` 填写 `Task 1` 或 `Task 2`，与目录一致。软件从 `meta` 读取题号、来源、题型和话题，用 `prompt.blocks` 或 `prompt.text` 展示题面，通过 `prompt.images` 关联本地图片，用 `modelAnswer` 展示范文。新增题目时保留题图子目录和文件名。

作答视图提供计时和实时词数。正式提交写入 `writing-submissions`，保存正文、题目标识和提交时间。再次打开同一题可查看最近一次提交。

## 成绩与恢复

| 数据 | 意义 |
|---|---|
| `id` | 本次提交的稳定标识，用于防重复 |
| `bankId`、`examId` | 题库来源和原题标识 |
| `points`、`possible` | 得分和总分，单位为分 |
| `details` | 保存逐题标准答案、用户作答、实际得分及满分 |
| `elapsedMs` | 毫秒。桌面新记录累计窗口前台时间。上游旧记录保留原用时字段转换后的毫秒数 |

桌面阅读草稿含当前答案、已累计用时和更新时间，正式提交时清理对应草稿。总览用正式成绩、已结束且有回答的口语会话和已提交作文计算四科次数与活动日期。题库进度按已作答的题目去重。

<!-- 2026-11-20：加入 AWL 静态词表及其原表字段说明。 -->
词汇基石从 `data/vocabulary/` 的 `ielts_core.json`、`ielts_538.json`、`awl.json` 与桌面 `reading-words` 集合读取词表。阅读词典同目录使用 `ecdict.json`。编辑和删除保存在 SQLite 的 `vocabulary-edits` 集合中，随工作区备份保存。删除的词从该词表和对应复习队列移除。条目标识沿用 `词表:原单词`，改拼写后仍使用原复习进度。

「AWL 学术词汇表」来自 `IELTS资料/词汇/` 下两份内容相同的 AWL PDF。每个词族占一个词条，10 个 Sublist 共 570 个词族。`wordFamily` 保存分组、原表斜体标示的常用词形、同族词形和来源页。去掉 `visualised` 在同一词族中的重复项后，共保留 2,541 个同族词形。原始词族信息与用户编辑的释义、音标等字段各自保存。

「538 考点词」来自 `IELTS资料/词汇/` 的总表和七份详解。按总表实际标红内容归并后，共 526 个词条，其中 376 个为主词。`words[].study.noteIds` 指向 `notes` 中的详解，替换词可共享一个或多个主词的讲解。详解按词头匹配并保留原 PDF 文件名、页码和编号。遇到拼写变体或编号顺序不同的词，仍关联到相应词头。分级和重要性排行保留在原表字段中。

## 备份

<!-- 2026-11-19：说明桌面恢复的事务边界与原版转换规则。 -->
桌面备份的 `format` 为 `ietls4pass-backup-v1`，包含 `records` 和 `documents`。新文件带 `sha256-` 校验值，按排序后的对象键、数组顺序和可往返的数值计算。旧文件使用结构校验，也可以恢复。合并时同标识资料保留本机版本。覆盖前在同一 SQLite 事务创建回退点，清除当前成绩、工作区文档及阅读草稿写者，再写入目标备份。工作区在预览后发生变化时需要重新预览。回退点支持下载、恢复和逐个删除，整库重置会一并清除。

原版 v1 成绩文件及 v2 全量或部分导出使用合并导入。原版 v2 校验总值、每个文档及各层成绩实体的 FNV-1a，并检查三层的记录标识一致。可识别的答案、分值、批注和已冻结前台计时随原版成绩保存，未保留证据的字段按未知处理。来源明确的单篇阅读草稿可通过阅读练习继续。

有可匹配成绩的原版文章复习计划、支持的外观选项、学习进度、阅读生词和同标识成就写入对应桌面集合。其余学习资料原始字段随 `settings` 下的 `legacy-import:<逻辑键>` 保存，例如浏览器活动会话、自定义词表及无法对应的批注。浏览器备份历史和内部运行状态由原版管理。

桌面备份包含目录的相对索引。换机时在设置中为恢复的索引重新选择原目录，沿用题库 ID。对于有明确自定义题库标识的原版阅读记录和草稿，同样可以选择对应目录。媒体和目录授权需在本机提供。

## 第二轮阅读数据

阅读的 `readingTiming` 记录题目、共享题组和未分配的前台毫秒数，带本次作答、题库来源和原题标识。时长只在窗口有焦点、页面可见且处于答题状态时累计。每个可归属的时段只进入一个桶。用户操作切换归属，共享题组只记录组的总时长。上次保存后可能遗漏的时间、超过五秒的不可观测间隔和缺失映射以覆盖原因记录。

`pendingResult` 仅存在于待提交草稿。提交前保存冻结答案与计时，重试沿用该结果。每个单篇草稿只有当前 SQLite 写者可更新。备份保存正式结果和已落盘草稿，恢复单篇草稿时重新取得写者。

`review-plans` 按题库和篇目存放文章复习状态。新成绩和自动调度在同一事务落库，回放反馈更新时按复习计划版本校验。阅读批注包括纯文本笔记、题目标记及原文高亮。在正式成绩的回放中编辑的批注以原成绩 ID 存在 `annotations` 集合。

单篇阅读草稿保存 30 天，可从阅读练习列表继续。恢复旧备份时先校验原件，再跳过套题成绩、套题草稿、中断归档及已识别的关联回放资料。

## 第三轮本机题库与学习工具

设置页使用原生目录选择器。SQLite 的 `bank_folders` 表保存目录绑定，题库数据保存相对路径和原版 ID。刷新复用同一目录与题库种类的 ID。打开资源时校验实际路径属于已绑定目录。备份中保存相对索引，目录访问绑定属于本机。

阅读支持原版 `reading-exams/manifest.js`、已转换阅读索引和能识别题目控件与答案的 HTML。听力可读取原版 `manifest.js`、`listening-index.compat.js`，或扫描 P1–P4 目录。已知结构化题源包括静态登记或内联答案字面量。自备 HTML 听力按 Section 存放，每个文件对应一节。仅可参考的 HTML 与 PDF 会显示状态。

本机媒体按相对路径关联。PDF 使用系统默认程序打开，题图和音频由桌面端读取。目录移动时可重新绑定。题源按 UTF-8 读入，单个文本资源读取上限 8 MiB，按 96 MiB 读取上限载入图像或音频。

ECDICT 条目及其 MIT 许可位于 `data/vocabulary/`。阅读生词以单词、题库、原题标识保存，轮内状态暂存于练习页，完成后将到期进度落库。成就以正式成绩投影，持久化已解锁时间。

## 第四轮本地诊断

SQLite 结构版本 4 新增诊断表，版本 5 增加口语目录绑定。诊断事件限固定操作名、结果和时间，报告另带应用版本。默认记录失败，详细模式在 15 分钟内也记录成功。SQLite 保存最近 7 天内至多 2,000 条。无法写入 SQLite 时，当前窗口保留最近 200 条失败事件。设置支持手动导出、清理、停用和结束详细记录。诊断与本机回退点由独立表保存，学习备份仅包含成绩和工作区资料。
