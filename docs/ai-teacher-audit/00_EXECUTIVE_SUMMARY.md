# IETLS4PASS 与 AI 教师前置审计

审计日期 2026-11-28。范围为当前 Windows 工作树及一个可读取的本机用户资料库。**VERIFIED** 指源码、配置或数据可核实。**PARTIAL** 指部分证据成立。**NOT_IMPLEMENTED** 指活动代码中没有该项业务实现。**UNKNOWN** 指环境、授权或证据不足。本报告将源码实现、实际样本、运行验证分别标注。

## 现有系统

**VERIFIED** IETLS4PASS 0.1.0 是 Tauri 2 桌面应用。React 18、TypeScript、Vite、HashRouter 和 TanStack Query 组成渲染层，Rust 与 rusqlite 管理工作区。四科题库是本地文件。练习记录和设置保存于本机 SQLite。前后端通过 Tauri invoke 通信，文件读取使用本机目录绑定或资源协议。真实库与源码的目标版本均为 9。[项目架构](01_PROJECT_ARCHITECTURE.md) · [数据库](06_DATABASE_AND_HISTORY.md)

| 科目 | 当前实现 | 作答证据 | 单次分析可用程度 |
|---|---|---|---|
| 听力 | VERIFIED 按册、场景、Section 浏览，音频作答、续做、判分、回看、题库详解、精听 | 正式答案、逐题分、Section 用时。当前题库可补原文、录音、句时间和解析 | PARTIAL 可做逐题事实核对与有证据的错因推断。缺少题到录音片段的稳定映射与用户播放行为 |
| 阅读 | VERIFIED 单篇答题、草稿、判分、批注、生词、解析与回放 | 正式答案、逐题分、原文与解析引用，部分题或共享组有前台归属时长 | PARTIAL 可分析原文证据与同义替换。定位常依赖文本启发式，旧记录时间和题源可能不齐 |
| 口语 | VERIFIED 真题话题内文本/语音回合、AI 考官、计时、会话历史，以及录音附件代码 | 用户消息与确认文本。含录音的回合可关联 WAV。此库没有用户作答或录音样本 | PARTIAL 文本可辅助词汇、语法和连贯性分析。完整流利度及发音需要实际音频分析，当前评分路径未接入 |
| 写作 | VERIFIED Task 分类、题面图与范文、编辑计词、计时、提交与历史 | 提交正文、题目 ID、Task 和日期。词数与计时显示在运行时 | PARTIAL 可做文本反馈。Task 1 的图在磁盘上可读，现有模型接口只接收文本。历史无用时、草稿或作文版本 |

**VERIFIED 本机样本** 有 1 条正式听力，10 个有内容的作答及 10 项判题。阅读有 2 份草稿，正式成绩 0。口语有 5 个会话（3 已结束），都只有考官消息，符合现行口径的正式口语为 0。写作提交 0。各科已接入的历史 AI 诊断 0。上述为这一库的只读快照，四科缺乏足够的纵向样本。[数据库与样本口径](06_DATABASE_AND_HISTORY.md)

## AI 教师接入判断

- **VERIFIED** 模型设置支持切换活动连接和模型，Rust 每次请求读取当前配置并组合磁盘 Markdown。当前业务调用是口语考官提问，另有设置连通性测试。语音输入走独立 DeepSeek ASR，考官 TTS 优先用本地 Kokoro。仓库下有口语和写作教师提示词原型，运行时未引用。[AI 基础设施](07_AI_INFRASTRUCTURE.md)
- **PARTIAL** 四科都有稳定的尝试或提交 ID。分析接入点在正式写入成功以后，四个业务边界不同。只有听阅共享正式成绩表，当前历史 UI 合并三路读取。现有记录可连接当前题库，普遍缺少内容快照或资源版本，无法承诺重建当时看到的版本。[接入位置](08_UI_AND_INTEGRATION_POINTS.md)
- **NOT_IMPLEMENTED** 「AI考官」下的学习诊断与针对训练是占位路由。总览的练习经验同样是占位。单次诊断、长期报告、薄弱点、专项训练和复测均缺少正式运行链与存储。[数据可用性](09_DATA_AVAILABILITY_MATRIX.md)
- **PARTIAL** 时间与科目聚合可由现有记录投影构造，能做练习量、客观题命中率及部分题型概览。需要区分资料缺失、未作答、计时不可用和缺少音频。长期诊断须避免从单题、旧题源或少量记录推断稳定能力。[缺口与风险](10_GAPS_AND_RISKS.md)

优先处理证据追溯、外部传输与使用授权、可比较的评分口径，以及写作图表和口语音频实际能否被选定模型消费。关于第三方真题、范文、解析及录音的可转交权限为 **UNKNOWN**。后续设计可直接从 [综合上下文](12_AI_TEACHER_CONTEXT.md) 开始，现有接口的原文见 [关键源码摘录](11_KEY_SOURCE_EXTRACTS.md)。
