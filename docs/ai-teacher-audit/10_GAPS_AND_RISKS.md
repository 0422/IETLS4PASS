# 数据缺口、复用边界与风险

重要事实以 **VERIFIED / PARTIAL / NOT_IMPLEMENTED / UNKNOWN** 表示。风险等级为面向后续设计的判断，区分与目前小样本中已经出现的错误。

| 风险及模块 | 确认状态与证据 | 对 AI 教师影响 | 等级 |
|---|---|---|---|
| 四科尝试数据结构与时间不同 | VERIFIED 已确认。听阅共享 `PracticeRecord`，口语会话以 `updatedAt` 投影，写作提交仅有 `submittedAt`。`records.ts`:9–47、四科类型 | 合并时要在统一查询层保留科目类型、时间含义和原始 ID。不能直接把口语更新时间当采集事件或写作时间 | 高 |
| 题 ID 来源不同、目录和内容可变 | VERIFIED 约束已确认，样本监听未观察错配。听力 Cambridge 标识与 rowId 分开，阅读别名，口语 part:id，写作 task:questionId，目录重绑或覆盖均可变。`listening.ts`、`banks.ts`、`speaking.ts`、`writing.ts` | ID 相等不足以认定证据版本相同；错误关联会污染分数和训练归因 | 高 |
| 历史可能少题面、题源或答案 | PARTIAL 旧导入字段可缺，眼前一条听力匹配。其他正式数据稀少。`legacyImport.ts`、[数据库](06_DATABASE_AND_HISTORY.md) | 历史结论需区分证据等级。题源丢失时限于提交快照，不应用当前假定的题面补历史 | 高 |
| 历史呈现不等于历史回溯 | VERIFIED 最近听力查看独立于全局指定记录，写作全局仅显示正文。`Listening.tsx::latestListeningResult`、`Records.tsx`:165–230 | 报告/复测必须绑定具体提交，否则出现错次或最新得分覆盖页面语境 | 高 |
| 草稿、过程和追踪不足 | VERIFIED 写作未保存草稿用时，听阅草稿保存最后快照。口语录音、正文的发送前草稿只在运行时。源码见 [UI](08_UI_AND_INTEGRATION_POINTS.md) | 不能用最终答案重建修改顺序、犹豫或资源使用。报告只能给带证据的假设 | 高 |
| 重复练习可能干扰评估 | VERIFIED 常规重复生成新 UUID，不覆盖正式提交。PARTIAL 删除历史和变动题源使首次状态、背熟和能力提升难区分 | 聚合按题和尝试双计口径。练习量可算，泛化能力需新题复测样本 | 中高 |
| 口语转写和语音证据不齐 | VERIFIED 转写只存确认文本，不存词级时间/置信度。语音可存 WAV，当前库无用户音频。`llm/asr.rs`、`store/speaking.rs` | 生词/语法误判可来自 ASR，字面流利不说明发音或可懂度 | 高 |
| 写作题图无法传给现有文本接口 | VERIFIED 图有 bytes，`TextMessage.content` 是字符串。`WritingExercise.tsx:21–43`、`llm.rs:95–120` | 图表类的数字、趋势与 Task Achievement 可能无证据。后续须有图文证据或降级 | 高 |
| AI 只返回文本，暂无教师结果追溯 | VERIFIED 口语考官结果在会话 JSON，Markdown 是 Prompt 和人工导出，不存在“教师报告只存 Markdown”的现状。`openai_compatible.rs`、`records.ts`、`store.rs` | 持久分析应有结构化输出、评分证据和版本，不能把生成 Markdown 当可靠共同数据结构 | 高 |
| Prompt 编辑可即时生效，历史版本缺失 | VERIFIED Markdown revision 用于防并发覆盖，没有历史快照或请求引用。`store/prompts.rs:96–167` | 相同答卷重跑可能变化，需关联当时的 Prompt、模型、参数和评分规则 | 高 |
| 现有请求逻辑偏文本且缺作业边界 | VERIFIED 考官和测试共用适配器，ASR 自身协议；没有业务重复的评分实现。无流、取消、自动重试、usage。`llm.rs`、`llm/openai_compatible.rs` | 需要设计请求预算和并发/幂等失败处理，不能复用一次 UI mutation 充当长任务组件 | 中高 |
| 迁移、回退和备份相容 | VERIFIED v1–v9、事务、兼容旧记录，旧套题和孤立回放过滤；语音及文档已进入备份。`store.rs:33–101`、`backup.rs` | 以后任何扩展都需处理旧行读兼容、缺版本、关联删除与重复恢复。本报告未迁移 | 高 |
| 长期输入长度、偏差与评估口径 | PARTIAL 当前全量读客户端，无题型/时间查询与证据检索。官方分数与单节/单篇比率口径不同。样本仅 1 次正式听力。`Records.tsx`、`StudyOverview.tsx` | 上下文不能无上限拼卷。先取范围、做本地统计与样本索引，按需调少量证据。实际规模极限 UNKNOWN | 高 |
| 第三方数据传输与个人隐私 | VERIFIED 当前话题/对话为外发文本，合法活动连接可外发语音。连接允许 HTTP(S)，密钥为本机 SQLite 列。用户资料保留和提供方政策 **UNKNOWN**。`llm.rs`、`asr.rs`、`ai_models.rs` | 分别处理转写、评分和云端模型的数据最小化、留存和退出管理；不能扩大个人数据外发 | 高 |
| 真题、录音、范文和解析授权 | UNKNOWN 本地文件有来源链接/导出标签，仓库代码许可和文件存在不证明有二次使用或发第三方服务授权。`meta.source`、README 与题库样本 | 是否可作为模型输入、共享和发布资料须另获可验证权利。测评证据应尽量引用、限量与标注 | 高 |

将客观错误、报告推断和用户自述分开，是之后比较趋势的前提。

## 可复用性

| 分类 | 资产或边界 |
|---|---|
| 可以直接复用 | 正式听阅结果的逐题结构、判分和总分；口语完成条件与通过 audioId 读取音频；写作提交正文；当前题库 DTO 与媒体 bytes；现有考试目标、时间范围 UI 交互。引用依具体模块 |
| 可以通过适配复用 | `records.ts` 的科目/时间投影，`useWritingSubmissions`、`desktop.records/documents`；题库可共享加载器；`learningActivity.ts` 的本地日历范围；`AnswerReview`、四科 history UI 与 Prompt compose；评分和输出校验需额外层 |
| 需要扩展 | 从原提交到题源证据版本；目录匹配的显式失败；听力题到句时间及阅读段落的证据；音频分析、写作图像、分科统计口径、时间范围检索与替代来源；Prompt 版本和评估链 |
| 尚未实现 | 教师分析、长期报告、弱项标签及证据、训练推荐或生成、训练保存和复测、资产许可/外发管理、结构化结果校验 |
| 暂时无法判断 | 用户当前服务商配置能否可靠评分、真实录音与图表识别精度、其他用户历史覆盖或真实负载、题源和部署后数据的许可。均标记 UNKNOWN |

后续设计可复用客观判分结果作为事实，再把错因作为有证据程度的模型判断。题源内容与用户回答均是输入数据，Prompt 中应隔离其指令语义。以上仅记录设计约束。
